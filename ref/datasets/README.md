# External datasets

Data files are **not** stored in this repository (size and licences). For
every dataset you use, add a folder here with a `README.md` containing:

```
Name:            DIAT-µSAT
Source / URL:
Licence / terms:
Access:          (open / account / e-mail request)
Version, date:
Papers to cite:
Local path:      data/raw/<name>/   (git-ignored, do not commit)
Used for:
```

The comparison of candidate datasets and the usage-conditions checklist are in
[doc/research/datasets.md](../../doc/research/datasets.md).
